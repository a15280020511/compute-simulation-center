# 参数校准使用规范

1. 先登记参数定义、单位、边界、先验依据和失效条件。
2. 先做 Morris 或低成本筛选，再集中校准高敏感参数。
3. 平滑连续模型优先 `least_squares`；显式等式或不等式约束使用 `slsqp`；多局部最优或非平滑模型才使用 `differential_evolution`；计数、概率或正值观测使用固定似然模式。
4. 校准必须保留多起点、参数区间、相关性、近优解和可识别性结果。
5. 优化器成功不等于模型有效。必须再次执行独立硬约束检查和样本外验证。
6. 参数不可识别时只能报告多个等价参数集合，不得把单一参数解释为真实机制。
7. 正式任务不得提交 Python 目标函数、似然函数或优化器代码。
